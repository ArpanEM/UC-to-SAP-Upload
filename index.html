Reminder — how RP Code works for Returns: every time you run a Sales Upload in this browser, the tool remembers each order/SKU's Shipping Package Code. When you later process a Return, it looks up RP Code from that memory by matching Sale Order Number + Product SKU Code. If a return's order was never seen in a Sales run on this browser, RP Code is left blank — it is never guessed. Sales history is stored in this browser only (not shared automatically across computers) — use Export / Import History under Settings to move it between machines.
