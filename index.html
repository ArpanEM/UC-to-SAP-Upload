Return Upload
Total = raw Total − Other charges; Unit Price = raw Total / Qty; RP Code is looked up from Sales history.
How RP Code works: every time a Sales Upload is processed in this browser (either from the Sales tab, or via the optional Sales file import below), the tool remembers each order/SKU's Shipping Package Code. When you process a Return, it looks up RP Code by matching Sale Order Number + Product SKU Code. If a return's order was never seen in a Sales run on this browser, RP Code is left blank — never guessed. History is stored in this browser only — use Export/Import History under the menu's Settings to move it between machines.
